# Termos de uso

**1. O que é.** Esta plataforma organiza os Dados Abertos CNPJ publicados pela Receita Federal
(informações cadastrais públicas de empresas, estabelecimentos e quadros societários).

**2. Uso permitido.** Os dados podem ser usados para finalidades legítimas, como análise de crédito
e de risco, prevenção a fraudes, due diligence, cumprimento de obrigações legais, prospecção B2B e
planejamento comercial ou logístico.

**3. Dados pessoais (LGPD).** Parte das informações refere-se a pessoas físicas (sócios,
representantes e empresários individuais). Elas são exibidas exatamente como a Receita publica,
com o CPF mascarado. Ao usar a plataforma você se compromete a:

- tratar esses dados apenas para a finalidade legítima que motivou a consulta;
- não usá-los para fins discriminatórios, ilícitos ou abusivos, nem para envio de comunicações
  não solicitadas em massa a pessoas físicas;
- não tentar reidentificar CPFs mascarados nem cruzar os dados para formar perfis de pessoas físicas
  sem base legal;
- atender aos direitos dos titulares quando você se tornar controlador desses dados.

**4. Registro de acessos.** Toda consulta é registrada (usuário ou chave de API, data, hora, IP e o
que foi consultado), conforme o Marco Civil da Internet e para fins de auditoria e segurança.

**5. Contas e chaves.** Credenciais são pessoais e intransferíveis. Comunique imediatamente qualquer
uso indevido. Contas e chaves podem ser suspensas em caso de violação destes termos.

**6. Limitações.** As informações refletem a última publicação mensal da Receita e podem estar
desatualizadas. A plataforma é fornecida no estado em que se encontra, sem garantia de que os dados
de origem estejam corretos ou completos.
